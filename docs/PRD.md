## 한 줄 정의

AI 에이전트가 동아리·학생회 행사비를 대신 쓸 때, 한도 판정은 AI가 아니라 코드와 온체인 `PolicyVault`가 하고, 모든 결제·차단·승인·중지를 제3자가 기록만으로 재구성할 수 있게 남기는 지출 통제·증거 계층. (U-R5 핵심 가치 "맞음", U-R3 사용자·상황)

## 배경 / 문제

- GWDC 2026 KOREA 해커톤 FuriosaAI×Bricksum 트랙 **챌린지 B(지출 통제·기록)** 출품작이다 (U-R1 "B: 지출 통제·기록 (추천)").
- 핵심 가치 (U-R5에서 사용자가 "맞음"으로 확인한 문장 원문): "AI에게 한도를 맡기지 않는다. AI(Qwen3)는 위임 문장을 정책으로 바꾸고 구매가 목적에 맞는지 판단만 하며, 실제로 돈을 쓸 수 있는지는 코드와 PolicyVault가 결정한다. 규칙만으로 막히는 요청은 LLM을 부르지 않아 토큰이 0이고, 차단도 온체인에 기록돼 제3자가 기록만으로 재구성할 수 있다."
- 데모 시나리오: 동아리·학생회 회계. 보기 설명 원문(U-R3): "'행사비 20만 원을 맡길게, 다이소·쿠팡만, 건당 5만 원 넘으면 물어봐' 같은 위임 문장이 자연스럽고, 돈을 맡긴 사람(회장)과 검사하는 사람(감사·회원)이 나뉘어 '제3자 재구성' 시연이 편합니다."
- 채택 아이디어(M, 사용자가 "PolicyVault로 확정"): ChatGPT가 추린 MVP "Agent Spending Control & Evidence Layer"를 세 가지 고쳐 채택 — (1) 모델 Qwen3-32B, 자연어→정책 변환은 function 하나를 auto로 호출하고 코드에서 검증 (2) ERC-4337 전체 대신 자체 `PolicyVault` 컨트랙트 (3) 차단 시 revert 대신 `SpendBlocked(reason)` 이벤트를 남기고 false 반환.
